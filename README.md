# Portafolio personal — Hazael Venegas
# Descripción del Proyecto
Este proyecto consiste en una página web de portafolio personal que presenta mi perfil como desarrollador Full-Stack Junior, mis habilidades técnicas y mis proyectos destacados. También incluye enlaces de contacto y redes sociales para facilitar la comunicación profesional.

### Tecnologías y técnicas utilizadas

HTML5 para estructurar el contenido de la página.

CSS3 para los estilos y la apariencia visual.

CSS Grid y Flexbox para organizar y distribuir los elementos.

Diseño responsivo mediante media queries para adaptar la página a computadoras, tabletas y dispositivos móviles.

Pseudoclase :hover para agregar efectos visuales interactivos.

Fuentes personalizadas mediante @font-face.

Git y GitHub para el control de versiones y la publicación del proyecto.
